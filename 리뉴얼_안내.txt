PULSE 37 · GitHub 업로드용 완성본

이 압축파일에는 HTML, CSS, JavaScript, 이미지와 실제 배경음악이 모두 포함되어 있습니다.
압축을 풀면 index.html이 바로 나오는 구조이며 별도의 빌드는 필요 없습니다.

반영 사항
- 폐기된 인물 프로필·이미지와 김민지의 기존 결속 정보 삭제
- 시타델: 시타델_홈.mp3 → audio/citadel.mp3
- 오멘: 오멘_홈.mp3 → audio/omen.mp3
- 심연재림교: 재림교_홈.wav → audio/abyss.mp3 (웹 재생용 256kbps MP3)
- 루멘: 루멘_홈.mp3 → audio/lumen.mp3
- 홍화: 홍화_홈.mp3 → audio/honghwa.mp3
- 세계관·키워드·길드 목록: 기존 공명의.mp3
- 하단 플레이바: 곡명을 표시하지 않고 현재 페이지와 BGM 상태만 표시
- 재생/정지, 볼륨, 탐색, 세력별 자동 전환 유지

GitHub 업로드
ZIP 자체가 아닌 압축을 푼 내용 전체를 사이트 저장소의 게시 폴더에 넣으세요.
index.html, renewal.css, renewal.js, music-config.js, audio 폴더와 이미지들의 상대 위치를 유지하세요.
기존 GitHub Pages 저장소라면 기존 파일을 교체하고 audio 폴더도 함께 업로드하세요.
.nojekyll 파일도 포함되어 있습니다.

로컬 확인은 index.html을 브라우저에서 열면 됩니다.
입장 버튼을 누르면 음악이 시작됩니다. 브라우저가 재생을 막으면 재생 버튼을 누르세요.
음악 설정에서 선택한 파일은 현재 브라우저에만 적용됩니다.
이번 버전은 이전 버전의 시험용 음악 설정과 분리하여 제공된 기본 음악이 먼저 적용됩니다.
